# Remediation checklist

Use this checklist when preparing a remediation plan for a confirmed finding.

- [ ] Identify affected assets and owners
- [ ] Determine blast radius and exposure
- [ ] Propose a minimal, safe fix (code/config change)
- [ ] List verification steps and expected outputs
- [ ] Create a rollback plan and timeline
- [ ] Communicate with stakeholders and schedule maintenance windows
- [ ] After deployment, run verification and capture evidence
